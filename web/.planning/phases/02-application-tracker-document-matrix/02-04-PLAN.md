    }

    Component logic:
    - Import `useTrackerStore` from `@/hooks/useTrackerStore` and `useTrackerHydration`
    - Import `toast` from `sonner`
    - Import `Plus, Check` from `lucide-react`
    - Import `Button` from `@/components/ui/button`
    - Read `isTracked` from store: `const tracked = useTrackerStore(s => s.isTracked(slug))`
    - Get `addEntry` and `removeEntry` from store
    - If not hydrated yet: render disabled placeholder button

    Click handler:
    ```typescript
    const handleClick = (e: React.MouseEvent) => {
      e.preventDefault();
      e.stopPropagation(); // Prevent Link navigation in ScholarshipCard
      onClick?.(e);
      if (tracked) {
        removeEntry(slug);
        toast.success("Removed from tracker");
      } else {
        addEntry(slug, title);
        toast.success("Added to tracker");
      }
    };
    ```

    Rendering (variant="full", default):
    - Untracked: `<Button variant="default" size={size}>` with Plus icon + "Track This" text
    - Tracked: `<Button variant="neutral" size={size}>` with Check icon + "Tracking" text

    Rendering (variant="icon"):
    - Untracked: `<Button variant="neutral" size="icon">` with Plus icon, `aria-label="Track this scholarship"`
    - Tracked: `<Button variant="neutral" size="icon">` with Check icon, `aria-label="Manage tracked scholarship"`
    - Add `title` attribute matching aria-label for hover tooltip

    All transitions use `motion-safe:transition-all duration-150`.
