## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, checkbox internal spacing |
| sm | 8px | Compact element spacing, gap between badges in card row |
| md | 16px | Default element spacing, card content padding (px-4) |
| lg | 24px | Card internal padding (px-6, py-6 — established by Card component) |
| xl | 32px | Gap between Kanban columns on desktop |
| 2xl | 48px | Page top/bottom padding |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Kanban column width: 280px on desktop, full-width on mobile (not a spacing token — a layout dimension)
- Drag handle hit area: 44px minimum touch target per WCAG 2.5.5
- Document checklist row height: 44px minimum for touch targets

## Typography

Uses existing type scale from `index.css`. Phase 02 uses these specific stops:

| Role | Token | Size | Weight | Line Height | Usage |
|------|-------|------|--------|-------------|-------|
| Caption | `text-caption` | 13px (0.8125rem) | 400 (Inter) | 1.45 | Document checklist item labels, timestamp metadata, CSV export link |
| Body small | `text-body-sm` | 15px (0.9375rem) | 400 (Inter) | 1.5 | Notes textarea content, document matrix body text, stage descriptions |
| Body | `text-body` | 17px (1.0625rem) | 400 (Inter) | 1.5 | Tracker card scholarship title, empty state body copy |
| Subhead | `text-subhead` | 21px (1.3125rem) | 400 (Archivo Black) | 1.35 | Kanban column headings, document matrix section headings |
| Heading | `text-heading` | 27px (1.6875rem) | 400 (Archivo Black) | 1.25 | Page title "My Applications", "Document Overview" |

Weight constraint: Archivo Black for headings (renders at 400 weight but is visually bold by typeface design). Inter at 400 for body. No additional weights needed — the existing system uses only these two.

Uses existing CSS custom properties. No new colors introduced. Phase 02 maps existing tokens to specific UI elements:

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` / oklch(96% 0.008 75) | Page background, Kanban board background |

## Interaction Contract

### Drag and Drop (Desktop)

| Interaction | Behavior |
|-------------|----------|
| Grab handle | 24px grip icon (GripVertical from Lucide) on left edge of card |
| Drag start | Card lifts with 8px shadow increase, opacity 0.9, border changes to `--main` |
| Drag over column | Column background lightens (opacity shift), dashed border appears |
| Drop | Card animates to new position with 150ms ease-out-expo transition |
| Cancel (Escape) | Card returns to original position with same 150ms transition |
| Keyboard | Tab to card, Enter/Space to pick up, Arrow keys to navigate columns, Enter/Space to drop |

### Drag and Drop (Mobile)

| Interaction | Behavior |
|-------------|----------|
| Long press | NOT used (conflicts with scroll). Use tap-to-move instead |
| Tap card | Expands card to show stage selector + full details |
| Stage selector | Horizontal pill row: tap target stage to move card |
| Confirmation | No confirmation needed for stage changes (easily reversible) |

### Document Checklist

| Interaction | Behavior |
|-------------|----------|
| Check document | Neo-brutalism checkbox (existing CSS in index.css), toggles on tap/click |
| Persist | Immediate localStorage write via TrackerStorage adapter |
| Summary update | Document matrix row updates in real-time (re-render on state change) |

### Notes Editor

| Interaction | Behavior |
|-------------|----------|
| Open | Tap/click "Add notes" or existing notes preview text |
| Editor | Textarea, auto-expanding, max 500 characters |
| Character count | "X/500" shown below textarea in caption text |
| Save | Debounced auto-save (500ms) to localStorage — no explicit save button |
| Close | Tap outside or press Escape |

### "Track This" Button

| Interaction | Behavior |
|-------------|----------|
| Not tracked | Button shows "Track This" with Plus icon, variant `default` (filled main color) |
| Already tracked | Button shows "Tracking" with Check icon, variant `neutral` (outline style) |
| Click when tracking | Shows dropdown: "Move to [stage]" options + "Remove from tracker" (destructive) |
| Sonner toast | "Added to tracker" or "Removed from tracker" confirmation toast |

### Export CSV

| Interaction | Behavior |
|-------------|----------|
| Click | Immediate download of CSV file, no modal |
| Filename | `scholarhub-applications-YYYY-MM-DD.csv` |
| Columns | Title, Stage, Deadline, Notes, Documents Completed, Date Added |

## State Contract

### Data Shapes (for UI rendering)

```typescript
// Kanban stage type
type TrackerStage = "researching" | "preparing" | "submitted" | "interview" | "result";

// Stage display config
const STAGE_CONFIG: Record<TrackerStage, { label: string; colorToken: string; icon: string }> = {
  researching: { label: "Researching", colorToken: "accent-sky", icon: "Search" },
  preparing:   { label: "Preparing",   colorToken: "accent",     icon: "FileEdit" },
  submitted:   { label: "Submitted",   colorToken: "main",       icon: "Send" },
  interview:   { label: "Interview",   colorToken: "warning",    icon: "Users" },
  result:      { label: "Result",      colorToken: "success",    icon: "Trophy" },
};

// Document checklist items (standard taxonomy)
const DOCUMENT_TYPES = [
  "transcripts",
  "recommendation_letters",
  "statement_of_purpose",
  "cv_resume",
  "language_test_scores",
  "financial_documents",
] as const;
```

### UI States

| State | What Renders |
|-------|-------------|
| Loading | Skeleton: 5 column placeholders with 2 pulsing card skeletons each (desktop), single column with 3 skeletons (mobile) |
| Empty (no tracked items) | `TrackerEmptyState` with illustration + CTA to browse scholarships |
| Populated (1-15 items) | Full Kanban board with cards distributed across stages |
| Dragging | Card with elevated shadow, source position shows dashed placeholder |
| Storage error | `StorageErrorBanner` at page top |
| Data corruption | Error card with "Reset Tracker" option |

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Keyboard drag-and-drop | dnd-kit `KeyboardSensor` with custom `coordinateGetter` for column navigation |
| Screen reader announcements | dnd-kit `Announcements` prop: "Picked up [title]. Currently in [stage]. Press arrow keys to move between stages." |
| Stage change | `aria-live="polite"` region announces "Moved [title] to [stage]" |
| Document checkbox | Native checkbox with `<label>` association, neo-brutalism CSS does not break semantics |
| Focus management | After card drop, focus returns to the dropped card |
| Reduced motion | `motion-safe:` prefix on all transitions (matches existing codebase pattern) |
| Color contrast | All stage colors use existing tokens verified at 4.5:1+ contrast ratio against their backgrounds |
